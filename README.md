# 倒班日历 · Shift Calendar

> 一款为**倒班 / 轮班**人群设计的微信小程序：把"上 N 天 / 休 M 天"的周期排班可视化成日历，红班绿休、月 / 周 / 年多视图、丝滑滑动切换、农历节气、备忘与倒计时，数据仅存本机。

## 功能特性

- **任意周期排班**：支持"上 N 天 / 休 M 天"（N、M 各 1–60），按起始日自动推算每一天是上班还是休班。
- **三视图**：月视图、周视图、年视图，顶部 Tab 一键切换。
- **自定义平滑滑动**：月 / 周视图之间用自写的 `touch + translateX` 三页滑动（非微信原生 `swiper`）——滑入的页面**实时变亮**、松手后**沿滑动方向继续滑动落定居中**，并露出相邻月份 / 周的暗色边缘预览。
- **红绿着色**：上班 = 红、休班 = 绿，一眼分辨。
- **农历 / 节气 / 节日**：每日同时显示农历日期、节气与常见节日。
- **手动覆盖**：个别日期可手动改成上班 / 休班（不影响周期推算，仅当天生效），并可一键清除。
- **日程备忘**：任意日期可添加多条备忘；首页有入口预览，agenda 页集中管理、可删除。
- **倒计时**：首页显示"距下次休班 / 上班还有 N 天"，以及本轮已进行到第几天。
- **分享海报**：自动生成当日状态海报（班 / 休、进度条、倒计时），可保存相册、可转发小程序（转发卡片带"今天上班 / 休班"文案）。
- **本地优先**：所有设置与备忘仅存于本机 `wx.storage`，不上传服务器，永久免费。

## 默认排班规则

| 项 | 默认值 |
|---|---|
| 上班天数 | 14 天 |
| 休息天数 | 7 天 |
| 周期起点（起始日） | 2026-09-24（周四，上班第 1 天） |
| 周起始日 | 周一 |

> 起始日被定为**周四**：即一轮上班的第 1 天，之后每 `上班天数 + 休息天数` 天循环一次。
> 可在"设置"页修改上班 / 休息天数、起始日、周起始日，或用"对齐到周四"一键回退到最近的周四。

## 运行 / 构建

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「导入项目」，目录指向本仓库根目录。
3. AppID 填 `wx88eab8b00f33b197`（或选择「测试号」体验）。
4. 编译即可在模拟器预览；保存文件会自动热编译。

> - 最低基础库建议 ≥ 2.19（`share` / `index` 用到 `wx.getWindowInfo`，已对旧版 `getSystemInfoSync` 做兜底）。
> - **无后端、无 npm 依赖、无构建步骤**，导入即跑。

## 核心模块说明

### 排班算法 `utils/shift.js`
- 所有日期运算基于 **UTC 零点**，避免手机跨时区 / 夏令时导致日期错位。
- `statusOf(dateKey, settings)`：返回某天是 `work` 还是 `rest`，叠加手动覆盖（`pins`）后给出最终状态。
- `countdownOf` / `dayNoOf`：倒计时与"本轮第几天"计算；`buildPreview` 给出接下来两轮的区间预览。

### 视图渲染 `pages/index/index.js`
- 月 / 周视图采用**自写三页 pager**（`.pager-track` + `translateX`），而非受控 `swiper`——
  受控 `swiper` 在 `bindchanging` 里 `setData` 会打断惯性动画，无法同时满足"滑入实时变亮 + 松手沿方向落定"，故自实现。
- 拖动期间 `transition: none` 跟手并按位移实时计算三页透明度；松手后只设一次目标值开 300ms 过渡；落定后瞬时重置回中间页（前后是同一月份，肉眼无跳变）。

### 本地存储 `utils/store.js`
- `shift_settings_v1`：排班设置（含 `pins` 手动覆盖）。
- `shift_notes_v1`：备忘（以 `YYYY-MM-DD` 为 key 的数组）。
- 读取时对旧默认起始日做自动迁移，保证老用户平滑升级。

## 数据存储与隐私

- 数据**仅保存在用户本机**，不依赖任何后端服务。
- 清除小程序缓存即清空所有设置与备忘；请在设置页谨慎操作「清空备忘 / 恢复默认」。

## 已知说明

- 农历数据覆盖常用年份区间（见 `lunar-data.js`），如需更早 / 更晚年份需补充数据。
- 海报分享依赖 canvas，部分低端机型生成略慢属正常现象。
- 数据精度与排班逻辑已通过 Node 离线自测（锚定日推算、班休计数、全年天数、农历取数）。
